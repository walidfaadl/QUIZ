# أرشيف اتفاقات المصالحة الفلسطينية

برنامج ويندوز (Electron) يجمع اتفاقات ووثائق المصالحة بين فتح وحماس والفصائل الفلسطينية، مع بحث متقدم.

## الوثائق المضمّنة (15)
إعلان القاهرة 2005 • وثيقة الأسرى 2006 • وثيقة الوفاق الوطني 2006 • اتفاق مكة 2007 • إعلان صنعاء 2008 •
اتفاقية الوفاق الوطني (الورقة المصرية) 2009/2011 • إعلان الدوحة 2012 • اتفاق الشاطئ 2014 • اتفاق القاهرة 2017 •
بيان الأمناء العامين 2020 • بيان حوار القاهرة 2021 • إعلان الجزائر 2022 • اجتماع العلمين 2023 • إعلان بكين 2024 •
مقترح لجنة الإسناد المجتمعي 2024.

لكل وثيقة: التاريخ، المكان، الراعي، الأطراف، الموقعون، الملخص، السياق، **أبرز البنود مصنّفة حسب المحور**، المآل، وروابط المصادر.

> **مهم:** «أبرز البنود» تلخيص تحريري وليس النص الرسمي الحرفي. النص الكامل يُضاف من داخل البرنامج
> (زر «إضافة النص الكامل»: لصق أو تحميل ملف ‎.txt) فيصبح قابلاً للبحث فوراً، أو بكتابته في الحقل `fullText` داخل `app/data.js`.
> راجع التواريخ والتفاصيل مع المصادر قبل الاعتماد عليها.

## الميزات
- **بحث متقدم:** كل الكلمات / أي كلمة / العبارة كما هي، `"عبارة"`، الاستبعاد `-كلمة`، البدائل `أو` / `|`، البحث ببداية الكلمة `كلمة*`.
- تجاهل التشكيل وتوحيد الهمزات والتاء المربوطة والألف المقصورة، وخيار «كلمة كاملة» يراعي السوابق (ال، و، ب، ل…).
- نطاق المطابقة: الوثيقة كلها أو البند/الفقرة نفسها، واختيار الحقول التي يُبحث فيها.
- تصفية حسب السنة، النوع، الراعي، الطرف، المحور، ووجود النص الكامل.
- نتائج مع مقتطفات مميّزة، والنقر ينقلك إلى الموضع داخل الوثيقة.
- **مقارنة حسب المحور** (الانتخابات، الحكومة، منظمة التحرير، الأمن…) بين أي وثائق تختارها.
- **خط زمني**، ملاحظات شخصية، إضافة اتفاقات جديدة، نسخ احتياطي (JSON)، طباعة، وضع ليلي.

## التشغيل
- بدون تثبيت: افتح `app/index.html` في أي متصفح.
- كبرنامج: `npm install` ثم `npm start`.
- بناء ملف التثبيت لويندوز (على ويندوز): `npm run dist` → `dist/PalAgreements-Setup-1.0.0.exe` و `PalAgreements-Portable-1.0.0.exe`.
- أو عبر GitHub Actions: سير العمل `Build Agreements App (Windows)` يبني الملفات ويرفعها كـ Artifact.

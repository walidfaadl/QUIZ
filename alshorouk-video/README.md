# فيديو جرافيك — الشروق الفلسطينية

فيديو ترويجي سريع الإيقاع (32 ثانية، 1920×1080، 30fps، 120 BPM) لموقع [alshorouk.ps](https://alshorouk.ps).

**الملف النهائي:** `alshorouk-promo.mp4`

## المشاهد
| الوقت | المشهد |
|---|---|
| 0–3.5s | شروق الشمس فوق الأفق ← ظهور الشعار «الشروق / AL SHOROUK» |
| 3.5–8s | السلوجن كلمة بكلمة على الإيقاع: «أخبار · فلسطين · كما هي» ← «PALESTINE NEWS, AS IT IS» |
| 8–9.5s | «أقسام الموقع — 12» |
| 9.5–21.5s | 12 قسماً، ثانية لكل قسم (عربي + إنجليزي + أيقونة) مع شريط «عاجل» |
| 21.5–23s | شبكة تجمع كل الأقسام |
| 23–28.5s | التبديل بين `alshorouk.ps/ar` و `alshorouk.ps/en` ← «باللغتين العربية والإنجليزية» |
| 28.5–32s | الختام: الشعار + السلوجن بالعربية والإنجليزية + alshorouk.ps |

## الملفات
- `index.html` — الأنيميشن كاملاً (مشغّل للمعاينة في المتصفح: افتحه واضغط Play / مسافة).
- `music.js` — يولّد الموسيقى (`music.wav`) برمجياً ومتزامنة مع القطع.
- `render.js` — يصوّر الإطارات بـ Playwright ويرسلها إلى ffmpeg.
- `fonts/` — Cairo و Montserrat (OFL).

## إعادة التصدير
```bash
node music.js
ffmpeg -i music.wav -c:a aac -b:a 160k music.m4a     # للمعاينة في المتصفح
NODE_PATH=$(npm root -g) node render.js              # يحتاج playwright + ffmpeg
```
لتعديل الأقسام أو الألوان: مصفوفة `SECTIONS` في `index.html`. التوقيتات في الكائن `T` (وتُنسخ في `music.js`).

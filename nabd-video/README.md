# فيديو جرافيك — نبض فلسطين 24

فيديو ترويجي سريع الإيقاع (≈32 ثانية، 1920×1080، 30fps) لموقع [naba24.ps](https://naba24.ps/ar)، بنفس فكرة فيديو الشروق لكن بهوية وموسيقى مختلفتين.

**الملف النهائي:** `nabd-promo.mp4`

- **الهوية:** خط نبض قلب (ECG) + شارة «24» + «مباشر LIVE»، بالأحمر والأسود مع الأخضر والأبيض.
- **الموسيقى:** 128 BPM من سلّم «مي» الصغير، بطابع الأخبار العاجلة. المقدمة دقات قلب مع صفير جهاز المراقبة، وبعدها إيقاع مكسور وهاي-هات مثل تكّات الساعة، مع باص عميق وضربات سينث.

| البيت (beat) | المشهد |
|---|---|
| 0–8 | خط النبض يُرسم ← ظهور الشعار |
| 8–18 | «نبض · فلسطين · 24 · ساعة» ← «نبض فلسطين على مدار الساعة / PALESTINE'S PULSE — 24/7» |
| 18–21 | «أقسام الموقع — 12» |
| 21–45 | 12 قسماً (بيتان لكل قسم) مع شريط «مباشر» |
| 45–48 | شبكة كل الأقسام |
| 48–60 | الموقع على الجوال يتبدّل بين العربية والإنجليزية ← «باللغتين العربية والإنجليزية» |
| 60–68 | الختام: الشعار + السلوجن + naba24.ps |

## إعادة التصدير
```bash
node music.js
ffmpeg -i music.wav -c:a aac -b:a 160k music.m4a
NODE_PATH=$(npm root -g) node render.js
```
الأقسام في `SECTIONS` داخل `index.html`، والتوقيتات (بالبيت) في `T`، ومنسوخة في `music.js`.

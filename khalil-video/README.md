# فيديو جرافيك — شبكة أخبار الخليل

فيديو ترويجي عمودي 9:16 (1080×1920، ≈30 ثانية، 30fps) جاهز لريلز إنستغرام وستوري فيسبوك وتلغرام.

**الملف النهائي:** `khalil-promo.mp4`

**الهوية البصرية:** شعار الشبكة الحقيقي (`logo.jpg`) بألوانه: الأخضر الفيروزي والذهبي، مع صورة ظلّية للحرم الإبراهيمي وبيوت البلدة القديمة وجزيئات ضوء متوهجة.

**المحتوى من حسابات الشبكة:** السلوجن «من قلب الخليل نبثّ لكم الخبر أولاً بأول ونواكب معكم الأحداث في عموم فلسطين»، وأرقام المتابعين (فيسبوك 211K، تلغرام 80,289، إنستغرام 66.8K)، ورسالة «كن مراسلاً ميدانياً في منطقتك».

**الموسيقى:** شرقية بطابع سينمائي، 110 BPM على مقام الحجاز من «ري»: عود وقانون مركّبان صوتياً، ودربكة بإيقاع المقسوم، ورق، وطبول تايكو، ووتريات، ونغمات إشعار.

| البيت (beat) | المشهد |

| 0–8 | حلقات ذهبية وخضراء تُرسم ويظهر الشعار ← «شبكة أخبار الخليل» |

## إعادة التصدير
```bash
node music.js
ffmpeg -i music.wav -c:a aac -b:a 160k music.m4a
NODE_PATH=$(npm root -g) node render.js        # W/H env vars change the viewport (default 1080x1920)
```
لتحديث الشعار استبدل `logo.jpg`، ولتحديث أرقام المتابعين عدّل المصفوفة `STATS` في `index.html`.

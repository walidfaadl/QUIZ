# فيديو جرافيك — شبكة أخبار الخليل

فيديو ترويجي عمودي 9:16 (1080×1920، ≈30 ثانية، 30fps) جاهز لريلز إنستغرام وستوري فيسبوك وتلغرام.

**الملف النهائي:** `khalil-promo.mp4`

**الهوية البصرية:** أزرق وتركواز زجاج الخليل مع الذهبي، زخرفة النجمة الثمانية، وصورة ظلّية للحرم الإبراهيمي وبيوت البلدة القديمة، وجزيئات ضوء متوهجة.

**الموسيقى:** شرقية بطابع سينمائي، 110 BPM على مقام الحجاز من «ري»: عود وقانون مركّبان صوتياً، ودربكة بإيقاع المقسوم، ورق، وطبول تايكو، ووتريات، ونغمات إشعار.

| البيت (beat) | المشهد |
|---|---|
| 0–8 | النجمة الثمانية تُرسم ← «شبكة أخبار الخليل» |
| 8–16 | «من قلب الخليل · أولاً بأول» مع صعود أفق الحرم الإبراهيمي ← عاجل / صور / فيديو / بث مباشر |
| 16–28 | فيسبوك ← إنستغرام @khaleelnews ← تلغرام t.me/khalelnews |
| 28–36 | «شبكة واحدة · ثلاث منصات»: الأيقونات تدور حول الشعار + الحسابات |
| 36–44 | شاشة قفل تنهمر عليها إشعارات الشبكة ← «لا يفوتك خبر · فعّل الإشعارات» |
| 44–54 | الختام: الشعار + «تابعونا على» + الحسابات الثلاثة |

## إعادة التصدير
```bash
node music.js
ffmpeg -i music.wav -c:a aac -b:a 160k music.m4a
NODE_PATH=$(npm root -g) node render.js        # W/H env vars change the viewport (default 1080x1920)
```
الشعار في الفيديو (النجمة + الحرم) مرسوم مؤقتاً؛ لاستبداله بشعار الشبكة الحقيقي عدّل الدالة `emblemSVG()` في `index.html`.

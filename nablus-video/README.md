# فيديو جرافيك — أخبار نابلس

فيديو عمودي 9:16 (1080×1920، 30 ثانية، 30fps) لريلز إنستغرام وستوري فيسبوك وتلغرام.

**الملف النهائي:** `nablus-promo.mp4`

**الهوية:** من حسابات الشبكة نفسها:
- الشعار الحقيقي (`logo.png`، نسخة شفافة من `logo.jpg`)، بالرمادي الفحمي والأحمر.
- قالب المنشورات: الشريط الأحمر المائل، وشارات «عاجل / خبر / تصريح»، وأفق المدينة الرمادي.
- خطوط الشعار الأفقية هي عنصر الحركة الأساسي: تتجمّع لتكوّن الشعار، وتصنع الانتقالات بين المشاهد.

**النصوص من البايو:**
- «صوت نابلس من قلب الحدث».
- «تغطية يومية لأهم الأخبار | عاجل | ميداني | مجتمعي».
- «بكل نزاهة ووضوح».
- «نبض المدينة .. لحظة بلحظة».

**الأرقام:** فيسبوك 233K، تلغرام 182,785، إنستغرام 34.1K.

**الموسيقى:** تراب حديث 140 BPM بإحساس نصف السرعة، من سلّم «فا» الصغير: 808 منزلق، وهاي-هات برولات، وتصفيق، ولحن بصدى، وتكّات للعدّادات.

| البيت (beat) | المشهد |
|---|---|
| 0–8 | خطوط الشعار تنزلق وتكوّن الدائرة ← الشعار الحقيقي ← «نبض المدينة .. لحظة بلحظة» |
| 8–22 | «صوت · نابلس · من قلب الحدث» بين جبلَي عيبال وجرزيم ← «تغطية يومية لأهم الأخبار»: عاجل / ميداني / مجتمعي ← «بكل نزاهة ووضوح» |
| 22–32 | فيد منشورات بقالب الشبكة، يتقلّب مع الإيقاع |
| 32–50 | فيسبوك ← تلغرام ← إنستغرام: عدّاد لكل منصة + اقتباس من وصفها |
| 50–58 | «449K+ متابع ومشترك عبر منصاتنا الثلاث» |
| 58–70 | الختام: الشعار + «صوت نابلس من قلب الحدث» + الحسابات |

## إعادة التصدير
```bash
node music.js
ffmpeg -i music.wav -c:a aac -b:a 160k music.m4a
NODE_PATH=$(npm root -g) node render.js
```
الأرقام في الكائن `PLAT` وفي `FOLLOW` داخل `index.html`.

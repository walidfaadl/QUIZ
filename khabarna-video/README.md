# فيديو جرافيك — خبرنا فلسطين

فيديو ترويجي سريع الإيقاع (≈34 ثانية، 1920×1080، 30fps، 124 BPM) لموقع [khabarna.ps](https://khabarna.ps).
الهوية مأخوذة من الموقع: شعار فقاعة الحوار الحمراء بالعلم، الخلفية الورقية، الخطوط السوداء المزدوجة، قائمة «الآن / Now» بالتوقيت الرقمي، زر «ع/EN»، والوضع الليلي.

**الملف النهائي:** `khabarna-promo.mp4`

**الموسيقى:** بطابع غرفة الأخبار: نقرات آلة كاتبة كإيقاع، وجرس الآلة الكاتبة عند كل قطع، وماريمبا، وطقطقة أصابع، وباص، ونغمة نحاسية قصيرة في البداية والنهاية.

| البيت (beat) | المشهد |
|---|---|
| 0–8 | الشعار يُرسم (الفقاعة ← العلم ← السطور) مع صوت كتابة ← «خبرنا فلسطين» |
| 8–18 | «أخبار · فلسطين · 22:04 · لحظة بلحظة» ← السلوجن بالعربية والإنجليزية |
| 18–24 | قائمة «الآن / NOW» بالتوقيتات |
| 24–26 | «أقسام الموقع — 12» |
| 26–50 | 12 قسماً (بيتان لكل قسم) مع شريط «الآن» وساعة حيّة |
| 50–53 | صفحة أولى تجمع كل الأقسام |
| 53–64 | الجوال: التبديل بين ع/EN ثم الوضع الليلي ← «باللغتين العربية والإنجليزية» |
| 64–70 | الختام: الشعار + السلوجن + khabarna.ps |

## إعادة التصدير
```bash
node music.js
ffmpeg -i music.wav -c:a aac -b:a 160k music.m4a
NODE_PATH=$(npm root -g) node render.js
```
الخطوط: Almarai و IBM Plex Sans Arabic و Fira Sans Extra Condensed و Share Tech Mono (OFL).
